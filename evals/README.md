# Astra Paints - Evals

Evals + visualization tooling for the painting runs, using the results dir.

## The tools

- `judge.py` (1 call): blind recognition judge that takes the final output and sees if it can understand what the final image is
- `contact.py` (free): round progression sheet saved in `contact.png`
- `plots.py` (free): coverage / cost curve from `run.json` -> `curves.png`
- `annotate.py`(free): captioned progression video saved in `progression.mp4` (in .gitignore but you can create your own)
- `compare.py` (free); two run dirs side by side with verdicts saved to `compare.png`

## Flow

Pipeline looks like paint -> judge -> contact / plots / annotate

## Run dir

Each run folder (`results/<subject>/<subject>-<agent>-<timestamp>/`) contains:

- `round_*.png` — canvas after each round
- `plan_*.json` — the model's raw plan per round (intent, before the arm executes)
- `final.png` — finished canvas
- `timelapse.mp4` — sim timelapse (gitignored, stays local)
- `run.json` — per-round and total stats: strokes, tokens, cost, plan/exec time, coverage
- `judge.json` — blind judge verdict and pass/fail
- `contact.png`, `curves.png`, `progression.mp4` — generated by the tools above
